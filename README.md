# 🧾 Will and Testament Contract (Soroban)

## 📖 Project Description

The Will and Testament Contract is a decentralized smart contract built on Stellar's Soroban platform. It enables users to securely define and manage how their digital assets should be distributed among beneficiaries after a specific trigger condition is met.

This project demonstrates how blockchain technology can be applied to estate planning by ensuring transparency, immutability, and automation.

---

## ⚙️ What It Does

This smart contract allows a user (the owner) to:

- Define a list of beneficiaries and their respective shares
- Update beneficiaries when needed
- Execute the will, marking the distribution as complete
- Query the contract state (beneficiaries and execution status)

⚠️ Note: This is a simplified implementation. Actual token transfers and death verification mechanisms are not included.

---

## ✨ Features

- 🔐 Owner-controlled contract initialization
- 👥 Multiple beneficiaries with share allocation
- 🔄 Update beneficiaries anytime before execution
- ✅ One-time execution of the will
- 🔍 Read-only functions for transparency
- 🧱 Built using Soroban SDK (Rust)
